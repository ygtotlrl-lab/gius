# גיוס

אפליקציית PWA לניהול גיוס כספים. עברית מלאה, RTL, מותאמת למובייל ולדסקטופ.

**כתובת האפליקציה** — `android.url` שבתצורה.

## הפעלה ראשונה

1. הריצו את `migrations/000_schema.sql` מול פרויקט ה-Supabase
   (`supabase.url` שבתצורה) דרך ה-SQL Editor — הוא הסכימה החיה, והרצה חוזרת
   אינה משנה דבר.
2. במסך ההגדרות: קבעו יעד חודשי וערכו את שש הרשימות (סעיפים, סוגי התחייבויות, אמצעי תשלום, שייכויות, שגרירים, תחומי משימות).

## מסכים

- **דשבורד** — מצב החודש מול היעד, פילוח לפי סעיף ולפי שגריר, מצב המשימות לכל אחראי ותשלומי החודש.
- **כרטיסים ותשלומים** — חיפוש, סינון ומיון; הכרטיס נפתח בתוך הרשימה עם פרטים, שייכויות, התחייבויות ותשלומים.
- **תכנית** — תכנית גבייה והתרמה לכל חודש, עם צפי מול בפועל.
- **משימות** — לכל אחראי שלושה שלבים: הרצה · השלמה · חסומה.
- **עוד** — רשומות (פתקים), הלוואות, תקציב אירוע והגדרות.

## פיתוח

הקליפה ב-`index.html`, והקוד ב-`app/` וב-`core/` — מודולים שהדפדפן טוען כמות שהם. אין build.

```bash
node tools/guard.mjs       # שומר הדחיפה — חובה לפני כל push
node tools/gen-app.mjs     # מחדש מהתצורה את קובצי הפלטפורמה והאייקונים
```
