# גיוס

אפליקציית PWA לניהול גיוס כספים. עברית מלאה, RTL, מותאמת למובייל ולדסקטופ.

**כתובת האפליקציה** — `android.url` שבתצורה.

## הפעלה ראשונה

1. הריצו את `migrations/000_init.sql` מול פרויקט ה-Supabase
   (`supabase.url` שבתצורה) דרך ה-SQL Editor. הקובץ אידמפוטנטי.
2. צרו את המשתמש הראשון **ידנית** ב-SQL Editor — ⛔ אין משתמש ברירת מחדל
   ואין סיסמה שכתובה בריפו (ר' ההערה בראש בלוק ה-seed שב-`000_init.sql`).
3. במסך ההגדרות: קבעו יעד חודשי, ערכו את רשימות הבחירה, והוסיפו משתמשים.

## מסכים

- **בית** — מצב החודש מול היעד, פילוח לפי סעיף ולפי שגריר, ו"מה שלי היום".
- **תורמים** — חיפוש, כרטיס תורם עם התחייבויות ותנועות.
- **התחייבויות** — רשימה עם מסננים וסטטוס מחושב.
- **משימות** — קנבן בארבעה שלבים עם יומן מצטבר.
- **הגדרות** — משתמשים, רשימות ויעדים (בעלים בלבד).

## פיתוח

הכל בקובץ אחד: `index.html`. אין build.

```bash
node tools/guard.mjs       # שומר הדחיפה — חובה לפני כל push
node tools/gen-app.mjs     # מחדש מהתצורה את קובצי הפלטפורמה והאייקונים
```
